2. **Standard Class.** A segment-only model reaches test ROC-AUC 0.5278 / PR-AUC 0.3993 vs the final model's 0.5292 / 0.3983. Second Class: 0.5623 vs 0.5666.

3. **Score clusters.** Calibrated scores are heavily discretised (isotonic steps): 31 unique values on validation, 41 on test. 22.7% of test orders sit within +/-0.01 of the largest Standard Class cluster (0.3991), i.e. 38.0% of Standard Class orders get essentially the same score, so ranking inside Standard Class is almost arbitrary.

A large swing for a small threshold shift means the threshold sits on a score cluster and is fragile.
